# Every rep verifies the guest checksum against bench_suite_x86_64.native.txt and

# from a run that computed the wrong answer or crashed.
#
# READ THIS BEFORE COMPARING.  Absolute wall times are load-dependent: this is a
# shared workstation and macOS offers no frequency pinning, no cpuset and no
# taskset.  Three 15-rep runs of the identical binary at different host loads are
# recorded below.  WITHIN a run the relative MAD is 0.1-2.9%; ACROSS runs the
# spread with host load reaches 15%.  Therefore:
#   - compare configurations only inside ONE interleaved bench_run.py invocation
#     (that is what bench_config_matrix.txt is for);
#   - never compare against a run whose recorded loadavg range does not overlap;
#   - prefer min_s over median_s when the loads differ; min is the closest thing
#     to an interference-free sample.
